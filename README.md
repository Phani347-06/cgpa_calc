# JNTUH SGPA & CGPA Calculator

A modern React calculator for JNTUH R22, R18, and R16 grade-point based results.

## Features

- Semester SGPA calculation with dynamic subjects
- Overall weighted CGPA calculation across semesters
- Percentage conversion using `(CGPA - 0.5) x 10`
- Grade dropdowns for O, A+, A, B+, B, C, F, and Ab
- Total credits and weighted points display
- Dark and light mode
- Local storage persistence
- Print/export to PDF through the browser print dialog
- Responsive mobile-first dashboard UI

## Run Locally

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:5173`.

## Build

```bash
npm run build
```
